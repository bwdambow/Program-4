# Program-4
Bratty Buns hot dog combos

# Description
Create menu in order to help Bratty Buns hot dog stand charge correct amount. It lists off all 128 combinations 
and each price

# Toppings & Price
ketchup: 0.15
Mustard: 0.17
Chopped Onions: 0.20
Tomato Wedges: 0.25
Sweet Relish: 0.30
Sport Peppers: 0.35
Sauerkraut: 0.45

# How it works
Each topping is represented by yes or no whether it is included or not which turns each combo into a binary number that the program uses to determine which combo to print.
